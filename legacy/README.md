# Legacy FHT draft

`fht-v0.1.json` is the legacy draft schema preserved verbatim from the root
`fht.json` at the start of the FHT 1.0 implementation (issue #7). It is kept for
audit and migration review; it is not the current contract and is not generated
from the LinkML model.

- SHA-256: `34eec2e5c0dd9355ec3ffe3bdff8861d80345336d779b94b5e8a3ccf8ea894aa`
- Historical examples written for it are preserved verbatim in
  [`examples/`](examples/). They are invalid against the current `fht.json`
  (numeric `schemaVersion`, `masking`, an `md5:` checksum, a string
  `assemblySoftware`, misindented FASTA YAML and a taxon URI that does not match
  the named organism) and are kept only for audit. Do not repair them in place.
  Valid synthetic examples for the current contract are in `../examples/`.

The migration from this draft is documented in
[`../docs/FHT-MIGRATION.md`](../docs/FHT-MIGRATION.md). Do not edit this file;
preserve historical bytes.
